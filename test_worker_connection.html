Worker 连接测试工具

Tampermonkey 配置指南

请在 Tampermonkey 脚本中添加以下代码：

// 设置全局配置
if (!window.JEV) window.JEV = {};
if (!window.JEV.STATE) window.JEV.STATE = {};

// ✅ 正确的 Worker URL 配置
window.JEV.STATE.workerUrl = "https://jevshop.bensonlove1986.workers.dev";

// ✅ 认证配置 (Bearer 方式)
window.JEV.STATE.authToken = "jevindustry2025";
准备就绪，点击按钮开始测试...
测试结果将显示在这里...

📌 重要提示：

  • 请确保使用的是部署到 Cloudflare 的 Worker URL，而不是本地调试 URL
  • 如果浏览器测试成功但 Tampermonkey 失败，请检查浏览器扩展权限设置
  • 如果所有测试都失败，请检查网络连接或尝试重新部署 Worker
  • 此页面在浏览器中运行，绕过了命令行工具的网络限制
