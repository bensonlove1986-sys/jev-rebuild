JEV客服系统 - Daojie聊天窗口模块集成指南

注意：此文件提供了集成说明和示例代码。实际集成时，需要将指定的代码片段添加到JEV系统的主页面或显相层HTML中。

步骤1：确保模块文件存在

确保 daojie_chat_panel.js 文件已正确放置在 /modules/ 目录下。

步骤2：在JEV系统页面中添加模块引用

将以下代码添加到JEV系统显相层HTML文件的 <head> 或 <body> 结束标签前：

<!-- JEV Daojie 聊天模块集成 -->
<script type="text/javascript" src="/modules/daojie_chat_panel.js"></script>
集成示例： 
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JEV客服系统显相层</title>
    <!-- 其他现有CSS和JS引用 -->
</head>
<body>
    <!-- 现有JEV系统内容 -->
    
    <!-- 添加Daojie聊天模块 -->
    <script type="text/javascript" src="/modules/daojie_chat_panel.js"></script>
</body>
</html>

步骤3：模块功能说明

  • 聊天按钮：右下角显示 "💬 聊天" 按钮，点击可打开聊天窗口
  • 状态指示器：右上角显示 "Chat (Daojie) Online/Offline" 状态灯
  • 聊天窗口：居中显示，尺寸为 400px × 600px，背景半透明灰色
  • 加载状态：显示加载中提示，5秒超时后显示错误信息
  • 安全设置：iframe 配置了适当的 sandbox 属性，禁止跨域脚本执行
  • 日志记录：所有操作记录到 localStorage，键名为 jev_chat_module_log_<timestamp>
安全注意事项：
  • 模块已配置安全的 iframe sandbox 属性，限制了跨域操作
  • 所有资源使用 HTTPS 协议加载
  • 添加了 X-Agent-Token 头部（通过配置变量）
  • 定期清理旧日志，避免 localStorage 溢出

步骤4：手动初始化（可选）

如果需要手动控制模块的初始化时机，可以在页面加载完成后调用：

// 手动初始化聊天模块
window.initializeDaojieChatModule();

或者直接创建实例：

// 创建聊天模块实例
const chatModule = new window.DaojieChatModule();

步骤5：测试与验证

模块加载后，应满足以下成功标准：

  1. 右下角出现 "💬 聊天" 按钮
  2. 右上角显示 "Chat (Daojie) Offline" 状态灯
  3. 点击按钮弹出聊天窗口
  4. 成功加载后状态灯变为绿色 "Chat (Daojie) Online"
  5. 控制台输出加载成功信息，包含加载时间
  6. localStorage 中存在聊天模块的操作日志
