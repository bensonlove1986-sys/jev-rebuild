【阶段一】异常文件筛选 / Phase 1: Abnormal File Screening

──────────────────────────────

使用 PowerShell 命令筛选出真正损坏或非 UTF-8 文件：


Get-ChildItem "D:\PDF转网页\JEV_Client" -Recurse -Include *.html,*.js,*.css,*.json,*.txt,*.md,*.ps1,*.bat |
Where-Object {
    ($_.Length -lt 512) -or
    ((Get-Content $_.FullName -Encoding Byte -TotalCount 3) -match 'ÿþ|þÿ')
} | Select-Object FullName, Length |
Out-File "D:\PDF转网页\JEV_Client\diagnostics\files_to_rebuild.txt" -Encoding UTF8

输出结果：

文件：diagnostics\files_to_rebuild.txt

含所有空文件与非UTF-8文件路径

Output Result:

Contains all empty files and non-UTF-8 file paths

【阶段三】统一编码与写入修复 / Phase 3: Unified Encoding and Write Repair

──────────────────────────────

确保全目录文件统一为 UTF-8 编码：


Get-ChildItem "D:\PDF转网页\JEV_Client" -Recurse |
ForEach-Object {
    $c = Get-Content $_.FullName -Raw -ErrorAction SilentlyContinue
    if ($null -ne $c) { Set-Content -Path $_.FullName -Value $c -Encoding UTF8 }
}

Ensure all files in the directory are uniformly encoded in UTF-8.

【阶段四】只读防护锁定 / Phase 4: Read-Only Protection Lock

──────────────────────────────

锁定所有关键文件防止再被误写：


Get-ChildItem "D:\PDF转网页\JEV_Client" -Recurse -Include *.html,*.js,*.css,*.json,*.ps1 |
ForEach-Object { $_.IsReadOnly = $true }
Write-Host "🔒 所有关键文件已设为只读防护。"

Lock all critical files to prevent accidental overwriting.
