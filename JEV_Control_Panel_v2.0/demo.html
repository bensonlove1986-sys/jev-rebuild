模块化架构层级

core/ - 核心逻辑层

config.js - 全局配置
api.js - 接口封装
logger.js - 日志模块
agents.js - 状态管理
strategy.js - 策略决策
utils.js - 工具函数

modules/ - 功能模块层

dashboard.js - 控制面板
alert.js - 告警监控
analytics.js - 数据分析
mailer.js - 邮件模块
wechat.js - 微信消息
form.js - 表单处理
whatsapp.js - WhatsApp渠道

入口文件

main.js - 启动入口
index.html - 调试入口

模块化使用示例

模块按需加载：通过配置文件控制模块的启用/禁用，优化资源使用
统一配置管理：所有配置集中在config.js，避免硬编码
标准化接口：每个模块导出标准接口，便于调用和替换
事件驱动通信：模块间通过事件总线通信，降低耦合度

1. 模块引入示例

// 标准模块导入方式
import { CONFIG } from './core/config.js';
import logger from './core/logger.js';
import dashboard from './modules/dashboard.js';

2. 模块导出标准

// 模块标准导出格式
export const Dashboard = {
  init(),
  render(),
  updateAgents(data)
};

3. 条件初始化示例

// 条件初始化邮件模块
async initOptionalModules() {   try {     if (CONFIG.USE_MAILER === true) {       mailerManager = await import('./modules/mailer.js');       await mailerManager.init();     }   } catch (error) {     logger.warning(`邮件模块初始化失败: ${error.message}`);   } }

4. 事件通信示例

// 触发事件
window.dispatchEvent(new CustomEvent('jev:mail:sent', {   detail: mailData }));

// 监听事件
window.addEventListener('jev:mail:sent', (event) => {   console.log('邮件发送成功:', event.detail); });
