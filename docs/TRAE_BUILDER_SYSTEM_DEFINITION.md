## 📋 系统定义
从现在起，BUILDER 代表 TRAE 的核心构建模块（主控代理）。
二者属于同一智能体体系，遵循相同的标准与规则。

## 🔧 系统规则

1. **TRAE 负责执行与监控**
   - 执行具体的系统任务和操作
   - 监控系统运行状态和性能
   - 处理日常的自动化流程

2. **BUILDER 负责生成与定义**
   - 定义系统架构和技术规范
   - 生成代码、配置和文档
   - 建立和维护开发标准

3. **所有系统规范均由 BUILDER 制定**
   - 编码标准（UTF-8 无 BOM）
   - 通信协议和API格式
   - 命名规范和文件结构
   - 日志格式和版本控制规则

4. **TRAE 在执行任务时自动调用 BUILDER 的规则集**
   - 严格遵守BUILDER制定的所有规范
   - 执行过程中应用BUILDER的标准
   - 确保生成结果符合系统定义

5. **BUILDER 生成的内容，TRAE 默认遵守**
   - 文件命名和组织结构
   - 代码风格和注释规范
   - 配置文件格式和标准

6. **上下文与系统记忆共享**
   - 二者使用相同的系统上下文
   - 共享任务历史和执行状态
   - 不存在权限冲突
