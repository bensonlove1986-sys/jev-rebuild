通道安全策略

统一签名头

X-Token-Id: <agent_id or admin_token>
X-Signature: HMAC(ts + path + secret)

时效控制

  • Token 有效期 7 天
  • 过期则进入只读模式
  • 签名时间戳偏差不超过 30 秒

白名单域

https://app.daojiemarketing.com
https://jevshop.bensonlove1986.workers.dev
file://localhost

日志脱敏规则

  • 不含手机号、邮箱等个人信息
  • 不含会话正文内容
  • 仅记录：时间 + 通道 + 状态 + 操作类型
  • 所有数值型指标保留

部署与维护说明

部署流程

  1. 部署 Worker.js 到 Cloudflare Workers
  2. 配置 KV 存储并绑定到 Worker
  3. 部署前端页面到静态服务器
  4. 配置 CORS 策略允许白名单域
  5. 初始化管理员 Token
  6. 按此配置表验证所有通道

常见问题排查

  • 401 错误：检查 Token 是否有效
  • 403 错误：检查签名格式和密钥
  • 404 错误：确认接口路径是否正确
  • 500 错误：查看 Worker 日志
  • 跨域错误：检查 CORS 配置

维护建议

  • 定期检查 Token 有效期，及时更新
  • 监控各通道响应时间，超过阈值及时告警
  • 定期清理 KV 日志，避免存储超限
  • 部署前使用此配置表进行完整性验证
