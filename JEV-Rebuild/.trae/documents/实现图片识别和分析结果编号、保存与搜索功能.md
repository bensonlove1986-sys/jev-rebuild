# 实现图片识别和分析结果编号、保存与搜索功能

## 需求分析
用户要求：
1. 为每张图片和分析结果添加编号
2. 保存分析结果到本地
3. 在DeepSeek按钮右边添加UI图标
4. 实现分析结果的搜索功能

## 实现计划

### 1. 为图片和分析结果添加编号系统
- 在DeepSeekPanel.tsx中添加图片编号生成逻辑
- 修改ocrAnalysisMap结构，包含编号信息
- 在UI中显示图片编号和对应的分析结果

### 2. 保存分析结果到本地存储
- 扩展saveDraftToStorage函数，支持保存分析结果
- 添加专门的分析结果存储函数
- 实现分析结果的加载和显示逻辑

### 3. 在DeepSeek按钮右边添加UI图标
- 修改ChatComposer.tsx，在DeepSeek按钮右边添加新的UI图标
- 设计并实现分析结果管理的UI组件
- 添加图标点击事件处理逻辑

### 4. 实现分析结果搜索功能
- 添加搜索输入框和搜索按钮
- 实现基于图片编号和分析内容的搜索逻辑
- 显示搜索结果列表

### 5. 优化用户界面
- 设计清晰的分析结果展示界面
- 添加分析结果的展开/收起功能
- 确保界面美观且易于使用

## 技术实现要点
- 使用localStorage存储分析结果
- 实现图片编号的自增机制
- 设计高效的搜索算法
- 确保UI响应迅速且用户友好
- 保持与现有代码的兼容性

## 预期效果
- 每张图片都有唯一的编号
- 分析结果自动保存到本地
- DeepSeek按钮右边显示新的UI图标
- 可以通过图片编号搜索分析结果
- 分析结果可以方便地查看和管理
