## 问题分析

**根本原因**：当收到客户新消息时，系统会触发 AutoDraftWorker 生成 AI 建议，但由于缺少必要的环境变量配置，导致生成失败。

**具体问题**：
1. `AutoDraftEngine.ts` 中检查 `DEEPSEEK_API_KEY` 环境变量（第 116-118 行）
2. `.env` 文件中未配置 `VITE_DEEPSEEK_API_KEY`
3. 当 API 密钥未配置时，`callDeepSeekAPI` 会抛出错误，导致 AI 建议生成失败

## 解决方案

### 步骤 1：添加环境变量配置
- 在 `ui-core/app/.env` 文件中添加 `VITE_DEEPSEEK_API_KEY` 配置
- 提供一个默认值或占位符，确保系统能够正常启动

### 步骤 2：优化错误处理
- 修改 `AutoDraftEngine.ts` 中的错误处理逻辑
- 当 API 密钥未配置时，提供更友好的错误信息
- 确保即使在 API 密钥未配置的情况下，系统也能继续运行

### 步骤 3：验证修复
- 重启开发服务器
- 发送测试客户消息
- 检查控制台日志，确认 AI 建议生成流程正常执行
- 验证 UI 中是否显示 AI 建议

## 预期结果

修复后，当收到客户新消息时，系统会：
1. 自动触发 AI 建议生成
2. 即使在 API 密钥未配置的情况下，也能提供明确的错误信息
3. 在 UI 中显示生成的 AI 建议（如果生成成功）或失败信息（如果生成失败）
