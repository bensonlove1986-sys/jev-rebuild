# 实现删除联系人功能

## 目标
在 WhatsApp 聊天列表中添加删除联系人的功能，包括选择框和删除按钮。

## 实现步骤

### 1. 修改 ConversationList.tsx
- 添加选择模式状态：`isSelectionMode`
- 添加选中联系人状态：`selectedContacts`
- 添加进入/退出选择模式的按钮
- 添加删除选中联系人的按钮
- 添加选择/取消选择联系人的方法
- 修改 ConversationListItem 组件，添加选择框

### 2. 修改 ConversationList.css
- 添加选择框相关样式
- 添加删除按钮相关样式
- 添加选择模式相关样式
- 添加选中状态相关样式

### 3. 实现功能
- 点击 "选择" 按钮进入选择模式
- 在每个联系人前面显示选择框
- 点击选择框可以选择/取消选择联系人
- 点击 "删除" 按钮删除选中的联系人
- 点击 "取消" 按钮退出选择模式

### 4. 技术实现
- 使用现有的 `removeChat` 方法删除联系人
- 保持模块化设计，不影响现有功能
- 确保选择模式和普通模式可以无缝切换
- 添加适当的动画和过渡效果

## 预期效果
- 普通模式：显示正常的聊天列表
- 选择模式：显示选择框和删除按钮
- 可以选择多个联系人进行批量删除
- 删除后自动更新聊天列表

## 代码结构
```
ConversationList.tsx
├── ConversationListItem (添加选择框)
├── 选择模式状态管理
├── 选择/取消选择逻辑
├── 删除逻辑
└── 样式调整

ConversationList.css
├── 选择框样式
├── 删除按钮样式
├── 选择模式样式
└── 选中状态样式
```
