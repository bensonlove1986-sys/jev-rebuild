# 实现翻译插件的直接发送功能和回答模式

## 需求分析

### 1. 添加直接发送按钮
- **位置**：在"使用翻译结果发送"按钮旁边
- **功能**：直接发送翻译结果，不需要先倒入到聊天框里
- **交互**：点击按钮后直接发送消息，不需要额外步骤

### 2. 添加回答模式
- **功能**：不仅能翻译原文，还能根据原文生成回答式的内容
- **交互**：添加一个切换开关，允许用户选择是翻译还是回答
- **实现**：修改翻译服务，支持回答模式的 API 调用

## 实现计划

### 1. 修改 TranslationPlugin.tsx
- **添加状态**：添加 `isAnswerMode` 状态，默认为 `false`
- **添加函数**：添加 `handleDirectSend` 函数，实现直接发送功能
- **修改接口**：更新 `TranslationPopupProps` 接口，添加新的属性
- **传递属性**：修改 `TranslationPopup` 组件的调用，传递新的属性

### 2. 修改 TranslationPopup.tsx
- **更新接口**：修改 `TranslationPopupProps` 接口，添加 `isAnswerMode`、`onAnswerModeChange` 和 `onDirectSend` 属性
- **添加按钮**：在底部操作区域添加"直接发送"按钮
- **添加切换开关**：添加一个切换开关，允许用户选择是翻译还是回答
- **更新布局**：调整底部操作区域的布局，容纳新的按钮和切换开关

### 3. 修改 translateService.ts
- **添加参数**：修改 `translateMessage` 函数，添加 `mode` 参数，支持 "translate" 和 "answer" 模式
- **修改 API 调用**：根据模式生成不同的 API 请求

### 4. 修改 worker-core/index.js
- **更新端点**：修改 `/api/translate` 端点，添加对回答模式的支持
- **调整系统提示**：根据模式生成不同的系统提示，回答模式使用更适合生成回答的提示

## 预期效果

1. **直接发送功能**：用户可以直接发送翻译结果，不需要先倒入到聊天框里
2. **回答模式**：用户可以选择生成回答式的内容，而不仅仅是翻译
3. **良好的用户体验**：新功能无缝集成到现有界面中，操作直观易用

## 技术要点

- 使用 React 状态管理实现模式切换
- 优化 API 调用，根据模式生成不同的请求
- 调整 UI 布局，确保新功能的可用性和美观性
- 保持代码结构清晰，与现有架构兼容
