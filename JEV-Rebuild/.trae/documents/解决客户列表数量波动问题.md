# 问题分析

**现象**：客户列表一开始正常（显示133个客户），后来变得不正常（减少到66个客户）。

**根本原因**：
1. 当收到实时消息时，`__WA_EMIT__` 函数会调用 `safeGetChats()` 方法
2. `safeGetChats()` 方法会先清空 `CUSTOMER_CACHE`，然后重新从 WhatsApp Web 的 Store 中获取聊天列表
3. WhatsApp Web 的 `window.Store.Chat.getModels()` 在不同时间点返回的聊天数量可能不同，导致客户列表数量波动

# 解决方案

修改 `__WA_EMIT__` 函数，不再在收到实时消息时调用 `safeGetChats()`，而是直接更新现有客户列表中的特定客户：

1. **移除对 `safeGetChats()` 的调用**：避免重新获取整个客户列表
2. **直接更新 `CUSTOMER_CACHE`**：只更新收到消息的客户的信息
3. **发送更新后的客户列表**：确保 UI 能收到最新的客户信息

# 预期效果

- 客户列表数量不会再出现波动
- 当收到实时消息时，只会更新相关客户的信息，不会影响其他客户
- 客户列表会保持稳定，不会出现一开始正常后来变得不正常的情况

# 代码修改点

**文件**：`worker-core/playwright-whatsapp-engine.js`
**函数**：`__WA_EMIT__`
**修改内容**：
- 移除 `safeGetChats()` 调用
- 添加直接更新 `CUSTOMER_CACHE` 的逻辑
- 添加发送更新后客户列表的逻辑

# 验证方法

1. 重启 worker-core 服务
2. 观察客户列表数量是否稳定
3. 发送或接收消息，检查客户列表数量是否仍保持稳定
4. 检查客户信息是否正确更新
