## 问题分析

前端无法接收图片的主要原因是：

在 `MessageBubble.tsx` 中，`getImageUrl()` 函数直接返回 `media_path` 作为图片的 `src`，但没有与 `API_BASE_URL` 拼接。这导致浏览器尝试从当前页面的域名加载图片，而不是从正确的 API 服务器加载。

具体来说：
- `media_path` 是相对路径，例如 `/api/media/r2/whatsapp/...`
- 浏览器会将其解析为 `https://当前页面域名/api/media/r2/whatsapp/...`
- 但正确的 URL 应该是 `https://API_BASE_URL/api/media/r2/whatsapp/...`

## 解决方案

修改 `MessageBubble.tsx` 中的 `getImageUrl` 函数，使用 `resolveUrl` 函数（或直接使用 `API_BASE_URL`）来构建完整的图片 URL。

## 修复步骤

1. **修改 `MessageBubble.tsx` 文件**：
   - 导入 `resolveUrl` 函数（如果尚未导入）
   - 修改 `getImageUrl` 函数，使用 `resolveUrl` 函数构建完整的图片 URL

2. **验证修复**：
   - 检查图片是否能够正常加载
   - 确保图片 URL 格式正确

## 预期效果

修复后，图片应该能够正常加载，前端应该能够正确显示 WhatsApp 消息中的图片。
