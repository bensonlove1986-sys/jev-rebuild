# AI回复依据UI设计计划

## 目标
在DeepSeekPanel组件中，在AI回复卡片上方添加一个"回复依据"卡片，显示AI生成回复所基于的客户消息，提供清晰的上下文信息。

## 设计方案

### 1. 新增回复依据卡片
- **位置**：AI回复卡片上方
- **样式**：与现有AI回复卡片风格一致
- **内容**：
  - 标题："回复依据"
  - 客户消息预览（支持多行文本）
  - 展开/收起按钮
  - 消息时间戳（可选）

### 2. 技术实现

#### 修改DeepSeekPanel.tsx
1. **新增状态**：
   - `showSourceMessageDetails`：控制是否显示完整的客户消息

2. **新增UI组件**：
   - 回复依据卡片容器
   - 客户消息预览
   - 展开/收起控制

3. **逻辑处理**：
   - 使用`currentLatestCustomerMessage`或`latestCustomerMessage`作为数据源
   - 实现消息文本的截断和展开功能
   - 确保与现有AI回复卡片的视觉一致性

#### 修改DeepSeekPanel.css
1. **新增样式**：
   - `.reply-basis-card`：回复依据卡片容器样式
   - `.reply-basis-header`：卡片标题样式
   - `.reply-basis-content`：消息内容样式
   - `.reply-basis-actions`：展开/收起按钮样式
   - `.reply-basis-timestamp`：时间戳样式

2. **调整布局**：
   - 确保回复依据卡片与AI回复卡片之间的间距合理
   - 确保在不同屏幕尺寸下的响应式表现

### 3. 交互设计
- **默认状态**：显示消息预览（截断长消息）
- **点击展开**：显示完整的客户消息
- **点击收起**：恢复到消息预览状态
- **无消息时**：显示占位符文本

### 4. 视觉设计
- **颜色**：使用与现有卡片一致的背景色和边框色
- **字体**：使用与现有文本一致的字体大小和样式
- **图标**：使用适当的展开/收起图标
- **动画**：添加平滑的展开/收起过渡动画

## 实现步骤

1. 修改DeepSeekPanel.tsx，添加回复依据卡片的HTML结构和相关状态
2. 修改DeepSeekPanel.css，添加回复依据卡片的样式
3. 测试在不同消息长度下的显示效果
4. 测试展开/收起功能的交互体验
5. 确保与现有UI的视觉一致性

## 预期效果
- 用户可以清晰地看到AI回复是基于哪条客户消息生成的
- 长消息可以通过展开/收起功能方便地查看
- 回复依据卡片与现有AI回复卡片风格一致，整体UI协调美观
- 提供了更好的上下文信息，有助于用户理解AI回复的依据
