# 实现消息气泡同时展示原文和发送内容

## 实现目标

* 在消息气泡的同一个 div 中同时展示原文和发送给客户的信息
* 特别是对于使用翻译助手发送的消息，清晰区分原文和发送内容
* 保持普通直接发送消息的原有显示方式
* 确保 UI 布局美观，易于理解

## 实现步骤

### 1. 扩展 Message 接口

* **添加翻译相关字段**：
  * 在 `Message` 接口中添加 `originalText` 字段，用于存储用户输入的原文
  * 添加 `translatedText` 字段，用于存储实际发送给客户的翻译内容
  * 添加 `translationInfo` 字段，存储翻译相关元数据

### 2. 修改 MessageBubble 组件

* **更新 renderMessageContent 函数**：
  * 检查消息是否有 `originalText` 和 `translatedText` 字段
  * 如果有，显示双重内容：原文（内部可见）和发送内容（客户可见）
  * 使用清晰的 UI 布局和样式区分两者
  * 保持普通消息的原有显示逻辑

* **添加新的渲染逻辑**：
  * 为双重内容消息创建专门的渲染函数
  * 确保布局美观，信息清晰
  * 添加适当的标签和分隔符

### 3. 更新 UI 样式

* **添加新的 CSS 类**：
  * `.message-content-original`：原文内容样式
  * `.message-content-sent`：发送内容样式
  * `.message-content-separator`：分隔符样式
  * `.message-content-label`：标签样式

* **优化布局**：
  * 使用 flexbox 或 grid 布局确保内容对齐
  * 添加适当的间距和边框
  * 使用不同的字体颜色或背景色区分原文和发送内容

### 4. 集成翻译助手流程

* **确保翻译助手发送的消息包含必要字段**：
  * 在翻译助手的发送逻辑中，确保设置 `originalText` 和 `translatedText` 字段
  * 保持与现有翻译助手逻辑的兼容性

### 5. 测试和优化

* **测试不同场景**：
  * 使用翻译助手发送的消息（显示双重内容）
  * 普通直接发送的消息（保持原有显示）
  * 入站消息的翻译显示（保持不变）

* **优化用户体验**：
  * 确保双重内容显示清晰易懂
  * 测试不同长度的文本内容
  * 确保响应式设计，适应不同屏幕尺寸

## 技术要点

* **条件渲染**：根据消息类型和字段动态决定显示方式
* **UI 设计**：创建清晰美观的双重内容布局
* **向后兼容**：保持现有功能不受影响
* **类型安全**：确保 TypeScript 类型定义正确

## 预期效果

* 使用翻译助手发送的消息：
  ```
  [原文]
  你好，这是中文原文
  
  [发送给客户]
  Hello, this is the English translation
  ```

* 普通直接发送的消息：
  ```
  这是直接发送的消息
  ```

* 入站消息：
  ```
  Customer's message
  
  [中文翻译]
  客户的消息内容
  ```

此实现将使翻译助手的使用更加透明，用户可以清晰看到自己输入的原文和最终发送给客户的内容。
