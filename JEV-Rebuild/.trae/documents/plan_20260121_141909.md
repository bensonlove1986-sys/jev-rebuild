## 修复WhatsApp实时消息接收问题

### 问题分析
1. **消息触发条件过于严格**：Engine中只有当消息满足`isNonFromMe && hasChatId && isNewMessage`条件时，才会调用`safeGetChats()`获取最新聊天列表
2. **消息事件可能未正确发送**：Engine可能没有正确捕获和发送所有类型的消息事件
3. **UI可能未正确接收消息**：需要确保UI能正确接收和处理所有消息事件
4. **消息格式可能不匹配**：Engine发送的消息格式与UI期望的格式可能不一致

### 修复计划
1. **放松Engine消息触发条件**：
   - 确保所有消息都能被正确发送到UI
   - 不限制只有非自己发送的消息才能触发更新
   - 不限制只有新消息才能触发更新

2. **确保Engine能正确发送消息事件**：
   - 检查并修复消息监听和发送逻辑
   - 确保`__WA_EMIT__`函数能正确发送所有消息事件
   - 确保`whatsapp:message`事件能被正确触发

3. **确保UI能正确接收消息**：
   - 检查并修复UI消息监听逻辑
   - 确保`whatsappWebSocketService.processNewMessage`函数能正确处理所有消息
   - 确保消息能被正确添加到存储中

4. **统一消息格式**：
   - 确保Engine发送的消息格式与UI期望的格式一致
   - 检查并修复消息字段映射逻辑

### 具体修改
1. 修改`playwright-whatsapp-engine.js`中的`__WA_EMIT__`函数
2. 修改Engine的消息触发条件，放松限制
3. 确保Engine能正确捕获和发送所有消息事件
4. 检查并修复UI消息处理逻辑
5. 测试实时消息接收功能
6. 测试消息显示功能

### 预期效果
- 当Engine收到消息时，能正确发送`whatsapp:message`事件
- UI能正确接收并处理`whatsapp:message`事件
- 消息能被正确添加到存储中
- 聊天界面能实时显示新消息
- 联系人列表能更新最后一条消息和未读计数
