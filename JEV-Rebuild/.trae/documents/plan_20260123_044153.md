# 修复聊天消息显示混乱的问题

## 问题分析
聊天消息显示非常混乱，主要问题包括：
1. **重复消息**：多条相同的消息重复显示
2. **时间顺序错乱**：消息没有按照正确的时间顺序显示
3. **内容重叠**：消息内容和特殊标记（如"tail-in"、"tail-out"、"forward-refreshed"等）混合显示
4. **格式混乱**：消息格式不统一，影响可读性

## 实现方案

### 1. 增强消息排序逻辑
- 确保消息按照正确的时间顺序显示
- 处理时间戳缺失或无效的情况
- 优化排序算法，确保排序结果稳定

### 2. 实现消息去重机制
- 基于消息内容、时间戳和发送者实现去重
- 使用Set存储已处理的消息ID，避免重复显示
- 过滤掉重复的消息，只保留一条

### 3. 过滤消息内容
- 移除特殊标记（如"tail-in"、"tail-out"、"forward-refreshed"等）
- 只显示实际的消息内容
- 清理消息文本，移除不必要的空格和换行符

### 4. 优化消息格式
- 统一消息格式，确保所有消息使用相同的字段
- 确保消息的sender、direction、text等字段都存在且格式正确
- 优化消息的显示样式，提高可读性

## 技术要点

1. **消息排序**：使用稳定的排序算法，确保消息按照正确的时间顺序显示
2. **消息去重**：基于消息特征实现去重，避免重复显示
3. **内容过滤**：移除特殊标记，只显示实际的消息内容
4. **格式统一**：确保所有消息使用相同的格式

## 实现步骤

1. 增强消息排序逻辑，确保消息按照正确的时间顺序显示
2. 实现消息去重机制，避免重复显示相同的消息
3. 过滤消息内容，移除特殊标记，只显示实际的消息内容
4. 优化消息格式，统一消息的字段和样式
5. 测试消息显示效果，确保所有消息都正确显示

## 预期效果
- 消息按照正确的时间顺序显示
- 没有重复的消息
- 只显示实际的消息内容，没有特殊标记
- 消息格式统一，可读性高
