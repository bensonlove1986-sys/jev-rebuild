## 问题分析

用户选择了两个时间设置的 div 元素，希望在这些元素中显示回复和生成的倒计时。

### 当前状态
- 系统已有完整的倒计时管理：`useCountdownStore`
- 自动生成和发送时已调用 `addCountdown` 添加倒计时
- 但时间设置的 div 中没有显示倒计时

## 修复方案

在 DeepSeekPanel.tsx 中修改时间设置的 div，添加倒计时显示功能：

### 1. 导入和使用 useCountdownStore
- 在组件中导入 `useCountdownStore`
- 使用 `useCountdownStore.getState().getCountdown(chatId)` 获取当前倒计时
- 使用 useEffect 监听倒计时状态变化

### 2. 修改回复时间设置 div
- 在回复时间设置的 div 中添加倒计时显示元素
- 当有发送倒计时时，显示剩余时间
- 当倒计时完成时，隐藏倒计时显示

### 3. 修改生成时间设置 div
- 在生成时间设置的 div 中添加倒计时显示元素
- 当有生成倒计时时，显示剩余时间
- 当倒计时完成时，隐藏倒计时显示

### 4. 样式调整
- 为倒计时显示添加适当的样式
- 确保倒计时显示与现有 UI 风格一致

## 预期效果

- **回复时间设置 div**：当有发送倒计时时，显示 "发送倒计时：X 秒"
- **生成时间设置 div**：当有生成倒计时时，显示 "生成倒计时：X 秒"
- **倒计时完成**：自动隐藏倒计时显示
- **样式**：倒计时显示与现有 UI 风格一致
