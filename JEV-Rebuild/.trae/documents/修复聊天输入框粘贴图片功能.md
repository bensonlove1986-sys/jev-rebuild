## 修复聊天输入框粘贴图片功能

### 问题分析
通过检查代码，我发现了以下问题：

1. **主要问题**：在 `ChatLayout.tsx` 中，`ChatComposer` 组件没有接收 `onSendImage` 回调函数，导致图片粘贴后无法发送
2. **次要问题**：`ChatComposer` 组件没有接收到 `chatId` 属性，影响图片上传时的路径生成

### 修复方案

1. **修改 ChatLayout.tsx**：
   - 添加 `handleSendImage` 函数，处理图片发送逻辑
   - 在 `ChatComposer` 组件调用中传递 `onSendImage` 和 `chatId` 属性

2. **修改 ChatComposer.tsx**：
   - 确保 `onPaste` 事件正确处理图片类型
   - 优化图片上传逻辑，添加更详细的错误处理和日志

3. **验证 API 端点**：
   - 确保 `/api/upload/media` 端点正确处理图片上传
   - 验证返回的 `media_path` 格式正确

### 实现步骤

1. **步骤 1**：在 `ChatLayout.tsx` 中添加 `handleSendImage` 函数
   - 实现图片消息的创建和发送逻辑
   - 使用 `appendMessage` 添加图片消息到聊天记录

2. **步骤 2**：更新 `ChatComposer` 组件调用
   - 传递 `onSendImage` 回调函数
   - 传递 `chatId` 属性

3. **步骤 3**：优化 `ChatComposer.tsx` 中的图片粘贴逻辑
   - 添加更详细的日志输出
   - 改进错误处理

4. **步骤 4**：测试功能
   - 测试粘贴图片功能是否正常工作
   - 验证图片是否正确上传并显示在聊天记录中

### 预期结果
- 用户可以通过 Ctrl+V 粘贴图片到聊天输入框
- 系统自动上传图片并生成图片消息
- 图片显示在聊天记录中
- 不影响现有的文本发送功能

### 技术要点
- 使用 `event.clipboardData.items` 处理剪贴板项目
- 对于图片类型，使用 `item.getAsFile()` 获取文件
- 实现完整的图片上传流程：剪贴板 → 上传到 R2 存储 → 生成 media_path → 返回结果
- 不将 base64 文本写入 textarea，保持输入框干净
- 走现有的 media → R2 → media_path 链路
