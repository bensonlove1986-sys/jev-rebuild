# 实现AI DEEPSEEK助手功能

## 实现目标
- 在聊天输入框旁边新增AI DEEPSEEK助手按钮
- 点击按钮后弹出可拖动、可扩大或缩小的弹窗
- 集成DEEPSEEK API实现自动回复功能
- 确保UI设计美观，符合模块化要求

## 实现步骤

### 1. 创建AI DEEPSEEK助手组件
- **文件结构**：
  - `ui-core/app/src/modules/chat_modular/components/AIDeepSeekAssistant/AIDeepSeekAssistant.tsx` - 主组件
  - `ui-core/app/src/modules/chat_modular/components/AIDeepSeekAssistant/AIDeepSeekPopup.tsx` - 弹窗组件
  - `ui-core/app/src/modules/chat_modular/components/AIDeepSeekAssistant/AIDeepSeekAssistant.css` - 样式文件

### 2. 实现核心功能
- **可拖动、可调整大小的弹窗**：
  - 复用TranslationPlugin中的拖动和调整大小逻辑
  - 实现平滑的动画效果
  - 添加边界检查，确保弹窗不超出屏幕范围

- **DEEPSEEK API集成**：
  - 创建API调用函数，调用DEEPSEEK的聊天完成接口
  - 实现防抖处理，避免频繁API调用
  - 处理API响应，提取自动回复内容

- **自动回复功能**：
  - 支持基于聊天上下文的自动回复
  - 提供多种回复风格选项
  - 允许用户编辑回复内容后发送

### 3. 集成到ChatComposer组件
- 在ChatComposer.tsx的工具按钮区域添加AI DEEPSEEK助手按钮
- 传递必要的props，如inputText、onSendMessage等
- 确保与现有组件（如TranslationPlugin和表情选择器）协调工作

### 4. UI设计和样式
- **按钮设计**：
  - 使用AI相关的图标（如🤖）
  - 添加悬停效果和工具提示

- **弹窗设计**：
  - 现代化的卡片式设计
  - 清晰的输入输出区域
  - 直观的控制按钮
  - 支持暗色模式

### 5. 测试和优化
- 测试拖动和调整大小功能的流畅性
- 测试DEEPSEEK API的响应速度和准确性
- 优化性能，确保弹窗操作流畅不卡顿
- 测试边界情况，如网络错误、API超时等

## 技术要点
- **模块化设计**：组件化实现，便于维护和扩展
- **性能优化**：使用requestAnimationFrame优化拖动和调整大小的性能
- **API集成**：使用fetch API调用DEEPSEEK接口，实现自动回复功能
- **用户体验**：流畅的动画效果，直观的操作界面
- **错误处理**：完善的错误处理机制，确保系统稳定性

## 预期效果
- 点击AI DEEPSEEK助手按钮后，弹出一个美观的弹窗
- 弹窗可以自由拖动，调整大小
- 基于DEEPSEEK API生成智能回复
- 用户可以编辑回复内容后发送给客户
- 整体UI风格与现有系统协调一致
