# 设计AI动作状态指示器

## 设计目标
在翻译模式切换器的右侧添加一个AI动作状态指示器，展示AI正在进行的动作，如正在读取信息、正在生成信息、正在发送信息。

## 技术实现方案

### 1. 修改MessageTimeline.tsx
- 添加AI动作状态管理：`aiActionState`状态变量，支持'idle'、'reading'、'generating'、'sending'状态
- 在翻译模式切换器div中添加AI动作状态指示器组件
- 实现状态更新逻辑，监听AI相关操作

### 2. 添加AI动作状态指示器组件
- 位于翻译模式切换器的右侧，使用flex布局
- 包含图标和文本信息
- 支持不同状态的视觉反馈

### 3. 设计CSS样式
- 在MessageTimeline.css中添加AI动作状态指示器样式
- 为不同状态设计不同的图标和颜色
- 添加动画效果，提升用户体验
- 确保响应式设计，在移动设备上正常显示

### 4. 状态定义
- **idle**：AI空闲状态，不显示指示器
- **reading**：AI正在读取信息，显示读取图标和文本
- **generating**：AI正在生成信息，显示生成图标和文本，添加脉冲动画
- **sending**：AI正在发送信息，显示发送图标和文本

### 5. 动画效果
- 脉冲动画：用于生成状态，增强视觉反馈
- 淡入淡出：状态切换时的平滑过渡
- 图标旋转：发送状态的发送图标旋转效果

## 预期效果
- AI进行操作时，在翻译模式切换器右侧显示相应的动作状态
- 状态切换时有平滑的动画过渡
- 与现有UI风格保持一致，提升整体用户体验
- 响应式设计，适配不同屏幕尺寸
