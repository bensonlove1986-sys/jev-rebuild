# 实现新消息到达时客户会话自动移动到顶部

## 问题分析

通过分析当前系统结构，我发现：

1. **联系人列表排序逻辑**：
   - `ContactList.tsx` 中的 `getDisplayContacts` 函数按 `updatedAt` 时间排序
   - 排序逻辑：`(chatB?.updatedAt || b.updatedAt) - (chatA?.updatedAt || a.updatedAt)`
   - 这意味着 `updatedAt` 时间越晚的联系人会排在越前面

2. **消息处理机制**：
   - `chatStore` 中的 `appendMessage` 方法会更新聊天的 `updatedAt` 字段
   - 当新消息到达时，`updatedAt` 会被设置为当前时间

3. **潜在问题**：
   - 虽然系统设计正确，但可能存在一些边缘情况需要优化
   - 排序逻辑可以进一步完善，特别是对未读消息的处理

## 解决方案

### 1. 优化 ContactList 排序逻辑

**修改文件**：`ui-core/app/src/modules/chat_modular/components/ContactList/ContactList.tsx`

**优化内容**：
- 增强排序逻辑，优先考虑未读消息的联系人
- 确保排序函数正确处理所有边缘情况
- 添加强制重新渲染的机制

### 2. 确保消息处理的可靠性

**修改文件**：`ui-core/app/src/modules/chat_modular/store/chatStore.ts`

**优化内容**：
- 确保 `appendMessage` 方法在所有情况下都能正确更新 `updatedAt`
- 增强错误处理，确保消息处理不会中断
- 添加详细的日志，便于调试和监控

### 3. 验证和测试

**测试内容**：
- 测试新消息到达时的排序效果
- 测试未读消息的优先级
- 测试不同类型消息的处理
- 测试系统的稳定性和性能

## 预期效果

- 当新消息到达时，对应客户的会话会立即移动到联系人列表的顶部
- 有未读消息的联系人会优先于无未读消息的联系人
- 系统响应迅速，用户体验流畅
- 排序逻辑稳定可靠，不会出现异常情况

## 技术实现要点

- 使用 React 的 `useCallback` 和 `useMemo` 优化性能
- 确保状态更新的原子性和一致性
- 实现合理的错误处理和边界情况处理
- 添加适当的日志记录，便于问题排查
