# 重新构建项目以启用双重内容显示功能

## 问题分析
- 双重内容显示功能的代码已经实现（在 MessageBubble.tsx 中）
- 服务器正在运行，但可能使用的是旧的构建版本
- 需要重新构建项目以包含新功能

## 解决方案
1. **停止当前服务器**：停止运行在端口 3000 的服务器
2. **重新构建项目**：在 ui-core/app 目录下运行构建命令
3. **重启服务器**：在新构建的目录中启动服务器
4. **验证功能**：访问应用程序并测试双重内容显示功能

## 执行步骤
1. 停止当前运行的服务器进程
2. 在 ui-core/app 目录下运行 `npm run build` 命令
3. 切换到 build 目录
4. 启动新的服务器实例
5. 访问 http://localhost:3000/ 验证功能

## 预期结果
- 服务器成功重启
- 应用程序加载新的构建版本
- 消息气泡能够正确显示原文和发送给客户的信息
- 双重内容显示功能正常工作
