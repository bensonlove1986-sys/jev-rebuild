# 实现图片双击放大和缩放功能

## 1. 需求分析
- 双击聊天中的图片，图片放大显示
- 支持放大/缩小操作
- 确保操作流畅不卡顿

## 2. 实现方案

### 2.1 修改 MessageBubble 组件
- 添加图片消息处理逻辑，区分文本和图片消息
- 为图片元素添加双击事件监听
- 确保图片显示美观，添加适当的样式

### 2.2 创建 ImageViewer 组件
- 实现模态框布局，用于显示放大的图片
- 添加缩放功能：
  - 鼠标滚轮缩放
  - 双击放大/缩小
  - 触摸手势支持（可选）
- 实现拖拽功能，允许移动图片
- 添加关闭按钮

### 2.3 状态管理
- 在全局或聊天模块中添加图片预览状态管理
- 记录当前预览的图片 URL
- 管理缩放级别和位置

### 2.4 性能优化
- 使用 React.memo 优化组件渲染
- 实现图片懒加载
- 使用 CSS transform 进行缩放，避免重排重绘
- 限制最大缩放级别，防止内存溢出

## 3. 代码修改

### 3.1 修改 MessageBubble.tsx
- 更新消息内容渲染逻辑，添加图片支持
- 为图片添加双击事件

### 3.2 创建 ImageViewer.tsx 组件
- 实现模态框结构
- 添加缩放和拖拽逻辑
- 添加事件监听和清理

### 3.3 修改 MessageBubble.css
- 添加图片样式
- 确保图片显示美观

### 3.4 修改 ChatLayout.tsx
- 添加 ImageViewer 组件
- 管理图片预览状态

## 4. 技术要点
- 使用 React hooks 管理状态和事件
- 使用 CSS transform 实现流畅缩放
- 实现事件委托，优化性能
- 确保响应式设计，适配不同屏幕尺寸
- 支持键盘操作，提高可访问性
