# 聊天输入框翻译插件实现计划

## 1. 核心组件设计

### 1.1 翻译插件主组件 (`TranslationPlugin.tsx`)
- 集成到 `ChatComposer.tsx` 的工具区域
- 提供翻译按钮和弹窗控制
- 管理翻译状态和目标语言选择

### 1.2 翻译弹窗组件 (`TranslationPopup.tsx`)
- 支持扩大缩小的弹窗UI
- 目标语言选择器
- 翻译结果显示
- 加载状态和错误处理

### 1.3 语言选择组件 (`LanguageSelector.tsx`)
- 支持常用语言快速选择
- 语言搜索功能
- 语言分组显示

## 2. 功能实现

### 2.1 翻译逻辑
- 集成现有的 `translateService.ts`
- 实时翻译预览
- 翻译结果缓存
- 错误处理和重试机制

### 2.2 交互功能
- 点击翻译按钮打开弹窗
- 选择目标语言自动翻译
- 支持调整弹窗大小和位置
- 点击发送使用翻译结果

### 2.3 性能优化
- 防抖处理，避免频繁翻译请求
- 翻译结果缓存
- 懒加载组件
- 平滑动画效果

## 3. 技术集成

### 3.1 与现有组件集成
- 修改 `ChatComposer.tsx`，添加翻译插件
- 保持与现有表情选择器的兼容性
- 确保键盘事件处理正常

### 3.2 API集成
- 使用现有的 DeepSeek API 翻译服务
- 支持多语言目标选择
- 处理API调用错误

### 3.3 样式设计
- 现代化弹窗样式
- 支持响应式设计
- 平滑的动画过渡效果
- 符合现有UI风格
