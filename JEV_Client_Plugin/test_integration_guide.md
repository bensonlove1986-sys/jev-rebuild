# JEV Plugin 模块集成测试指南

## 测试概述

本测试页面专为验证JEV Plugin中的`register.js`和`toggle_manager.js`模块集成而设计。通过此测试平台，您可以：

- 模拟JEV环境初始化
- 动态加载并测试本地模块
- 验证注册激活功能和权限管理
- 测试功能开关控制和权限限制
- 监控模块间事件传递
- 调试集成过程中的问题

## 快速开始

### 准备工作

1. 确保您的JEV Plugin项目结构完整，特别是以下文件：
   - `jev_plugin_core.js`（核心文件）
   - `modules_local/register.js`（注册模块）
   - `modules_local/toggle_manager.js`（开关管理模块）

2. 将测试页面`test_integration.html`放在JEV_Client_Plugin目录下

### 基本测试流程

1. **启动测试页面**
   - 直接在浏览器中打开`test_integration.html`
   - 或通过本地服务器访问（推荐）：`http://localhost:8080/JEV_Client_Plugin/test_integration.html`

2. **初始化环境**
   - 点击「初始化JEV环境」创建模拟环境
   - 点击「加载本地模块」导入register.js和toggle_manager.js

3. **测试模块功能**
   - 在各个选项卡中测试相应功能
   - 按照测试用例逐步验证

## 功能模块说明

### 1. 核心测试流程控制

提供环境初始化和模块加载功能，是测试的基础步骤。

- **初始化JEV环境**：创建模拟的JEV全局对象和配置
- **加载本地模块**：动态导入register.js和toggle_manager.js
- **重置所有状态**：清空环境，重新开始测试

### 2. 注册模块测试

验证注册模块的核心功能，包括激活、注销和权限管理。

- **邀请码激活**：使用测试邀请码（如test123）激活插件
- **检查激活状态**：验证当前激活状态
- **注销登录**：清除激活状态和权限信息
- **获取权限信息**：查看当前用户权限配置
- **测试API连接**：验证API连接状态

### 3. 开关管理器测试

测试功能开关的管理、状态控制和权限应用。

- **初始化开关管理器**：启动开关管理功能
- **加载/保存开关状态**：测试状态持久化
- **批量操作**：启用/禁用/重置所有功能开关
- **功能开关列表**：直观展示所有功能状态和权限限制
- **权限映射配置**：查看功能与权限的映射关系

### 4. 集成交互测试

验证register.js和toggle_manager.js模块之间的协同工作。

- **权限同步测试**：测试注册模块向开关管理器同步权限
- **功能可用性测试**：检查特定功能的可用性状态
- **权限限制测试**：验证无权限情况下的功能限制
- **事件传递测试**：测试模块间事件通信机制

### 5. 事件监控

实时监控JEV相关事件的触发情况。

- 记录所有JEV相关事件
- 显示事件详情和传递数据
- 支持事件监听开关控制

### 6. 调试信息

提供详细的调试日志，帮助排查问题。

- 支持不同级别的日志过滤（全部、信息、警告、错误）
- 实时记录操作和系统状态
- 详细的错误信息展示

## 模块集成技术要点

### register.js 与 toggle_manager.js 集成关键

1. **权限数据同步**
   - register.js激活成功后，通过`jev_authenticated`事件传递权限数据
   - toggle_manager.js监听该事件并更新内部权限状态
   - 使用`setFeatures`方法批量更新功能权限

2. **权限与功能映射**
   - 通过`featureToPermissionMap`定义功能与权限的映射关系
   - 激活后自动应用权限限制到相应功能
   - 无权限功能将被锁定，无法启用

3. **事件驱动架构**
   - 使用自定义事件进行模块间通信
   - 关键事件包括：
     - `jev_authenticated`：认证成功
     - `jev_feature_toggled`：功能状态变更
     - `jev_connection_status_changed`：连接状态变更
     - `jev_features_permissions_updated`：权限更新
     - `jev_features_permissions_cleared`：权限清除

4. **权限检查机制**
   - 在启用功能前检查是否有权限
   - 提供`checkFeatureAvailability`方法验证功能可用性
   - 权限不足时返回详细原因

## 常见问题排查

### 模块加载失败

- 检查文件路径是否正确
- 确保文件名大小写匹配
- 验证文件内容是否有效（无语法错误）

### 权限同步不生效

- 检查权限JSON格式是否正确
- 验证`setFeatures`方法是否被正确调用
- 查看事件日志，确认`jev_authenticated`事件是否触发

### 功能开关操作失败

- 检查是否已激活插件
- 验证是否有权限操作该功能
- 查看调试日志中的具体错误信息
