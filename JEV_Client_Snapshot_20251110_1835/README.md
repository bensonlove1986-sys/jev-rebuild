# JEV 嘉尔威在线服务助手 v2.0.0

支持本地 Agent + 云端 Worker 自动切换的在线服务助手系统模块化插件。

## 项目简介

JEV在线服务助手是一个基于Tampermonkey的模块化浏览器插件，采用现代化的鲜亮设计风格UI，支持本地Agent与云端Worker的自动切换，提供聊天、翻译、AI推荐、小工具等多种功能。

## 核心特性

- 🏗️ **模块化架构**：所有功能模块独立加载，可热更新
- 🎨 **玻璃绿科技风格**：现代化UI设计，视觉体验更佳
- 🔄 **双模式切换**：支持本地Agent与云端Worker自动切换
- 📱 **响应式设计**：适配不同设备屏幕
- 🛡️ **安全稳定**：严格的错误处理和资源管理
- 🔧 **丰富工具**：内置多种实用小工具
- 🔔 **智能通知**：版本更新、状态变化实时通知

## 安装方法

1. 确保您的浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 Tampermonkey 控制面板
3. 点击「添加新脚本」
4. 复制 `jev_chatbot_plugin.user.js` 的内容粘贴进去
5. 点击「文件」→「保存」或使用快捷键 Ctrl+S
6. 插件将自动启动

## 使用说明

### 基本操作

- **打开插件**：点击 Tampermonkey 菜单中的「JEV 智能客服」
- **关闭插件**：点击插件窗口右上角的关闭按钮
- **最小化**：点击窗口右上角的最小化按钮
- **移动窗口**：拖动窗口顶部的标题栏

### 功能模块

#### 聊天模块
- 发送消息：在输入框中输入文字，按Enter或点击发送按钮
- 翻译文本：输入文本后点击翻译按钮，支持中英文互译
- 历史记录：自动保存聊天历史，刷新页面后可恢复

#### AI推荐模块
- 生成推荐：根据上下文自动生成AI推荐语
- 使用推荐：点击推荐卡片上的「使用」按钮直接插入到聊天输入框
- 复制内容：点击「复制」按钮复制推荐内容

#### 小工具模块
- **单位换算**：支持长度、重量、面积、体积等常见单位换算
- **汇率转换**：实时汇率转换功能
- **时间工具**：时间戳转换、日期计算、时区转换
- **文本处理**：大小写转换、去除空格、反转文本、字数统计

#### 设置模块
- **连接设置**：配置本地Agent和云端Worker地址
- **连接模式**：支持自动选择、仅本地、仅云端三种模式
- **系统状态**：查看连接状态、延迟等信息
- **高级设置**：自动检查更新、自动保存草稿等选项
- **数据管理**：导出/重置设置功能

#### 版本检测模块
- 检查更新：手动检查最新版本
- 更新日志：查看版本更新内容
- 更新设置：配置自动检查频率和通知选项

## 配置说明

### 环境变量

插件使用以下环境变量配置连接信息：

- **本地Agent地址**：默认为 `http://localhost:1820`
- **云端Worker地址**：默认为 `https://control.jevshop.workers.dev`
- **连接模式**：默认为 `auto`（自动选择）

这些配置可以在「设置」模块中修改并保存。

### 本地Agent配置

如需使用本地Agent功能，请确保：
1. 本地已运行JEV服务端
2. 服务端口为1820（或在设置中修改）
3. 服务端API与插件兼容

## 常见问题

### 连接失败
- 检查本地Agent是否正在运行
- 验证网络连接是否正常
- 在设置中调整连接模式
- 尝试使用云端模式

### 功能异常
- 检查浏览器控制台是否有错误信息
- 尝试刷新页面或重启插件
- 清除浏览器缓存后重试

### 性能问题
- 关闭不必要的模块
- 清理聊天历史记录
- 检查浏览器扩展冲突

## 开发说明

### 模块开发规范

1. **命名规则**：
   - 模块文件：全小写 + `.js`
   - 模块注册名：与文件名一致
   - 全局变量：使用 `window.JEV_*` 命名空间

2. **模块结构**：每个模块必须实现以下方法
   - `render(container)`：渲染模块UI
   - `init()`：初始化模块逻辑
   - `destroy()`：清理资源

3. **日志规范**：使用 `console.log('[JEV][模块名] 消息')`

4. **安全规则**：
   - 禁止直接使用 `fetch`，必须通过 `JEV_CONNECTION.send()`
   - 本地存储使用 `JEV_STORAGE` 并以 `JEV_` 前缀命名键
