# JEV 控制面板修复说明

## 修复内容概述

我已经对 JEV 控制面板进行了全面修复，主要解决了以下问题：

1. **重复加载问题** - 实现了严格的单例模式，确保页面上只有一个控制面板实例
2. **连接检测问题** - 修复了服务连接检测逻辑，确保正确识别服务状态
3. **拖拽和布局问题** - 优化了面板拖拽功能，增加了边界限制
4. **稳定性增强** - 使用更可靠的定时器机制，添加了资源清理功能

## 修复版本

- **当前版本**: 1.4.1
- **原始版本**: 1.4.0

## 使用方法

### 第一步：清理旧实例（重要！）

在安装修复版本前，请先清理页面上可能存在的旧面板实例：

1. 打开浏览器开发者工具（按 F12）
2. 切换到控制台（Console）标签
3. 复制并粘贴以下代码，然后按 Enter 键执行：

```javascript
fetch('d:\\PDF转网页\\reset_jev_panel.js').then(r => r.text()).then(eval);
```

或者直接复制 `reset_jev_panel.js` 文件中的全部内容到控制台执行。

### 第二步：重新加载控制面板

1. 刷新当前网页
2. 如果使用 Tampermonkey，可能需要重新启用脚本

### 第三步：验证修复效果

1. 确认页面上只有一个控制面板实例
2. 检查连接状态显示是否正确
3. 尝试拖拽面板，确认位置调整功能正常
4. 检查"未连接"状态是否已经解决

## 调试工具

### 调试脚本使用方法

如果仍然遇到问题，可以使用提供的调试工具：

1. 打开浏览器开发者工具
2. 在控制台中执行：

```javascript
fetch('d:\\PDF转网页\\debug_jev_panel.js').then(r => r.text()).then(eval);
```

这将输出详细的调试信息，包括：
- 全局变量状态
- 面板元素检测
- 服务连接测试结果
- 可能的冲突检测

## 服务端口确认

请确认以下服务端口是否正在运行：

- Agent: 1820
- Control Center: 1821
- AI Service: 1822

可以使用以下命令检查端口状态：

```
netstat -ano | findstr "1820 1821 1822"
```

## 常见问题排查

1. **面板重复显示** - 执行重置脚本后刷新页面
2. **连接不上** - 检查服务是否正在运行，端口是否正确
3. **拖拽功能不工作** - 确认浏览器没有禁用拖拽功能
4. **面板位置异常** - 关闭所有标签页，重新打开浏览器
