# JEV客户端HTML文件编码问题修复指南

## 问题分析
您的JEV客户端HTML文件显示乱码，这通常是由于文件编码不一致或包含BOM（字节顺序标记）导致的。由于自动化脚本执行超时，建议按照以下手动步骤修复。

## 方法一：使用记事本修复单个文件

1. **备份原始文件**
   - 复制要修复的HTML文件到`d:\PDF转网页\备份`目录
   - 例如：复制`D:\PDF转网页\JEV_Client\ui\panel.html`到`d:\PDF转网页\备份\panel.html.bak`

2. **使用记事本打开文件**
   - 右键点击HTML文件 → 打开方式 → 选择记事本

3. **另存为UTF-8编码**
   - 在记事本中点击「文件」→「另存为」
   - 在「保存类型」下拉菜单选择「所有文件(*.*)」
   - 在「编码」下拉菜单选择「UTF-8」
   - 点击「保存」覆盖原文件

4. **检查并添加meta标签**
   - 在记事本中编辑文件，确保在`<head>`标签内有：
     ```html
     <meta charset="UTF-8">
     ```
   - 如果没有`<head>`标签，在`<html>`标签后添加：
     ```html
     <head>
         <meta charset="UTF-8">
     </head>
     ```

## 方法二：使用Visual Studio Code批量修复（推荐）

如果您有VS Code：

1. **安装VS Code**（如果没有）
   - 从官网下载并安装：https://code.visualstudio.com/

2. **打开JEV_Client文件夹**
   - 在VS Code中点击「文件」→「打开文件夹」→ 选择`D:\PDF转网页\JEV_Client`

3. **搜索所有HTML文件**
   - 点击搜索图标（放大镜）
   - 搜索模式选择「文件」，输入`*.html`

4. **批量转换编码**
   - 选择一个HTML文件 → 右下角点击编码显示（如「UTF-8」或「GB2312」）
   - 选择「通过编码重新打开」→ 尝试选择「UTF-8」或「GB2312」
   - 成功打开后，再次点击右下角编码 → 选择「通过编码保存」→ 选择「UTF-8」

5. **批量添加meta标签**
   - 使用搜索替换功能（Ctrl+Shift+H）
   - 搜索：`<head>`
   - 替换为：`<head>
    <meta charset="UTF-8">`
   - 点击「替换所有」

## 关键文件列表
优先修复以下关键文件：
1. `ui\panel.html`
2. `ui\login_portal.html`
3. `ui\visual_learning_panel.html`
4. `ui\client_portal.html`
5. `main.html`

## 完成修复后的步骤

1. **清除浏览器缓存**
   - 关闭所有浏览器窗口
   - 重新打开浏览器时，按 `Ctrl+Shift+Delete`
   - 选择「缓存的图像和文件」
   - 点击「清除数据」

2. **重启JEV客户端**
   - 确保所有JEV进程已关闭（可以在任务管理器中检查）
   - 重新运行 `jev_start.bat`

## 如果问题仍然存在

1. **重新安装客户端**
   - 备份您的重要数据
   - 卸载并重新安装JEV客户端

2. **检查系统区域设置**
   - 右键点击「开始菜单」→「设置」→「时间和语言」→「区域」
   - 确保「区域格式」设置为「中文（简体，中国）」
